# Mambu

> Mambu is a SaaS cloud banking platform — a composable, API-first core banking engine that banks, neobanks, fintechs, lenders, and non-financial brands use to build and run lending, deposit, payment, and Islamic banking products across 65+ countries for 230M+ end users. This is an API Evangelist profile generated from Mambu's public developer documentation.

## APIs

- [Mambu API v2](https://docs.mambu.com/api/pages/api-v2/welcome/): REST API v2, base URL https://{tenant}.mambu.com/api. HTTPS Basic auth or apikey header; Idempotency-Key supported.
- [Mambu Payments API](https://docs.mambu.com/api/): Payment orchestration and connectivity.
- [Mambu Streaming API](https://docs.mambu.com/api/pages/streaming/streaming-index/): Resumable cursor-based event stream (add-on).
- [Mambu Audit Trail API](https://docs.mambu.com/api/): Audit event retrieval.
